# Linux — data নিয়ে কাজের জন্য যেটুকু লাগে

ক্লাস ২-এর সাথে রাখার জন্য। মুখস্থ করবেন না — দরকারের সময় দেখে নেবেন।
দুই সপ্তাহ ব্যবহার করলে এমনিতেই মনে থাকবে।

---

## কোথায় আছি, কী আছে

| কমান্ড | কী করে |
|---|---|
| `pwd` | এখন কোন ফোল্ডারে আছি |
| `ls` | এই ফোল্ডারে কী আছে |
| `ls -lh` | সাইজ, তারিখ, অনুমতি সহ |
| `ls -lhS` | সাইজ অনুযায়ী সাজিয়ে — বড়টা আগে |
| `cd folder` | ওই ফোল্ডারে ঢোকা |
| `cd ..` | এক ধাপ পেছনে |
| `cd ~` | নিজের ঘরে |
| `cd -` | আগে যেখানে ছিলাম |
| `mkdir -p a/b` | ফোল্ডার বানানো, মাঝেরটাসহ |
| `cp a b` | কপি · `cp -r` ফোল্ডারের জন্য |
| `mv a b` | সরানো বা নাম বদলানো |
| `rm a` | মোছা — **ফেরত পাওয়া যায় না** |

## ফাইলের ভেতরে কী আছে

| কমান্ড | কী করে |
|---|---|
| `head -5 f` | উপরের ৫ লাইন |
| `tail -5 f` | নিচের ৫ লাইন |
| `tail -f f` | লাইভ দেখা — নতুন লাইন এলেই দেখাবে |
| `wc -l f` | কয়টা লাইন |
| `less f` | পাতা উল্টে পড়া (`q` দিয়ে বের হবেন, `/` দিয়ে খুঁজবেন) |
| `cat f` | পুরোটা ছাপানো — বড় ফাইলে দেবেন না |

> বড় ফাইল সবসময় `head` দিয়ে শুরু করুন। `cat` দিলে এক লাখ লাইন স্ক্রিনে
> গড়াতে থাকবে, আর `Ctrl + C` চাপা ছাড়া উপায় থাকবে না।

## খোঁজা

| কমান্ড | কী করে |
|---|---|
| `grep "ERROR" f` | যে লাইনে ERROR আছে |
| `grep -c "ERROR" f` | কয়টা লাইনে আছে, শুধু সংখ্যা |
| `grep -i "error" f` | ছোট-বড় হাতের তফাত না দেখে |
| `grep -v "INFO" f` | যে লাইনে INFO **নেই** |
| `grep -n "ERROR" f` | লাইন নম্বরসহ |
| `grep "^2026-10-17" f` | যে লাইন এটা দিয়ে **শুরু** |
| `grep -r "TODO" .` | ফোল্ডারের সব ফাইলে |

## কেটে নেওয়া, সাজানো, গোনা

| কমান্ড | কী করে |
|---|---|
| `cut -c1-10` | প্রতি লাইনের ১–১০ নম্বর অক্ষর |
| `cut -d',' -f3` | কমা দিয়ে ভাগ করে ৩ নম্বর ঘর |
| `cut -d'&#124;' -f2` | পাইপ দিয়ে ভাগ করে ২ নম্বর ঘর |
| `sort` | সাজানো |
| `sort -rn` | সংখ্যা ধরে, বড় থেকে ছোট |
| `uniq -c` | একই লাইন কয়বার — **আগে sort লাগবে** |
| `tr -d ' '` | ফাঁকা জায়গা মুছে দেওয়া |

## জোড়া লাগানো

```bash
# | মানে — বাঁয়েরটার ফল ডানেরটায় পাঠাও
grep "| ERROR |" app.log | cut -c1-10 | sort | uniq -c | sort -rn

#  >  নতুন ফাইলে লেখো (আগেরটা মুছে যাবে)
#  >> ফাইলের শেষে যোগ করো
grep "| ERROR |" app.log > errors.log
echo "আরেকটা লাইন" >> errors.log
```

ছোট ছোট টুল, প্রতিটা একটা কাজ ভালো করে করে, আর পাইপ দিয়ে জুড়ে বড় কাজ —
এটাই Unix-এর মূল ভাবনা। পঞ্চাশ বছর ধরে টিকে আছে।

## অনুমতি

```bash
ls -l script.sh      # -rwxr-xr-x  এরকম দেখাবে
chmod +x script.sh   # চালানোর অনুমতি দেওয়া
./script.sh          # চালানো
```

`r` পড়া · `w` লেখা · `x` চালানো। তিনটা দল — মালিক, গ্রুপ, বাকি সবাই।

## Environment variable

```bash
echo $HOME           # নিজের ঘরের ঠিকানা
echo $PATH           # কমান্ডগুলো কোথায় খোঁজা হয়
export API_KEY=abc   # এই টার্মিনালের জন্য বসানো
env | grep API       # কী কী বসানো আছে
```

পাসওয়ার্ড আর API key কোডে লিখবেন না — `.env` ফাইলে রাখবেন, আর সেটা
`.gitignore`-এ দেবেন। এই অভ্যাসটা সপ্তাহ ৬-এ আবার আসবে।

## cron — নিয়ম করে চালানো

```bash
crontab -e           # নিজের সময়সূচি খোলা
crontab -l           # কী কী আছে দেখা
```

```
মিনিট  ঘণ্টা  দিন  মাস  বার   কমান্ড
  0     2     *    *    *    /home/sadat/run.sh      # রোজ রাত ২টায়
 */15   *     *    *    *    /home/sadat/check.sh    # প্রতি ১৫ মিনিটে
  0     6     *    *    1    /home/sadat/weekly.sh   # সোমবার ভোর ৬টায়
```

WSL-এ cron নিজে থেকে চালু থাকে না। একবার চালু করে নিতে হয়:

```bash
sudo service cron start
```

সপ্তাহ ১৯-এ Airflow আসবে, যেটা cron-এর অনেক বড় ভাই — আগেরটা ফেল করলে
পরেরটা থামিয়ে রাখা, ভাঙলে আবার চেষ্টা, ভেঙে থাকলে খবর দেওয়া।

## আটকে গেলে

| অবস্থা | কী করবেন |
|---|---|
| কমান্ড থামছে না | `Ctrl + C` |
| `less` বা `man` থেকে বের হতে | `q` |
| কমান্ডটা কী করে জানতে | `man ls` বা `ls --help` |
| আগের কমান্ড ফিরিয়ে আনতে | উপরের তীর, বা `Ctrl + R` দিয়ে খোঁজা |
| লম্বা নাম লিখতে | কয়েক অক্ষর লিখে **Tab** চাপুন |
| স্ক্রিন পরিষ্কার করতে | `clear` বা `Ctrl + L` |

**Tab চাপার অভ্যাসটা আজই করুন।** যাঁরা Tab ব্যবহার করেন আর যাঁরা করেন না,
তাঁদের গতির পার্থক্য দিনে কয়েকশো সেকেন্ড।
