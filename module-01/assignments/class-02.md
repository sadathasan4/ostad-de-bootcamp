## ছোট্ট একটা টোকা

ক্লাসে আমরা লিখেছিলাম `grep "| ERROR |"` — দুই পাশে পাইপ চিহ্ন দিয়ে।
WARN-এর বেলায় হুবহু ওভাবে লিখলে **শূন্য** আসবে।

কারণটা মজার। ফাইলে level-এর ঘরটা পাঁচ অক্ষরের জায়গা নিয়ে বসে আছে:

```
| ERROR |          ERROR পাঁচ অক্ষর, ঠিকঠাক বসে গেছে
| WARN  |          WARN চার অক্ষর, তাই পরে একটা বাড়তি ফাঁকা জায়গা
```

তাই WARN খুঁজতে লিখবেন `grep "| WARN"` — শেষের পাইপটা বাদ দিয়ে।

এটা মনে রাখার মতো একটা জিনিস: কম্পিউটার ফাঁকা জায়গাও গোনে। আপনার চোখে
যেটা "একই রকম", তার কাছে সেটা আলাদা।

## জমা দেওয়ার নিয়ম

উত্তরগুলো একটা ফাইলে লিখবেন। ফাইল বানানোটাও কমান্ড দিয়েই করুন — এটাও
অনুশীলনের অংশ।

```bash
echo "অ্যাসাইনমেন্ট ২ — আপনার নাম" > assignment-02.txt
echo "" >> assignment-02.txt
echo "১. CSV লাইন: " >> assignment-02.txt
```

খেয়াল করুন — প্রথমটায় একটা `>` (নতুন ফাইল), পরেরগুলোয় দুইটা `>>`
(শেষে যোগ)। প্রথমটায় ভুল করে `>>` দিলে পুরোনো কিছু থেকে গেলে মিশে যাবে,
আর পরেরগুলোয় একটা `>` দিলে আগের লেখা মুছে যাবে।

এরপর ফাইলটা খুলে উত্তরগুলো বসিয়ে দিন:

```bash
nano assignment-02.txt
```

সেভ করতে `Ctrl + O` তারপর এন্টার, বের হতে `Ctrl + X`।

ফাইলটা দেখতে এরকম হবে:

```
অ্যাসাইনমেন্ট ২ — রহিম উদ্দিন

১. CSV লাইন: 46908
২. log লাইন: ...
৩. WARN: ...
৪. DEBUG: ...
৫. ১০ অক্টোবরের ERROR: ...
৬. সবচেয়ে বেশি WARN: 2026-10-XX, XXX টা
৭. bKash অর্ডার: ...

বোনাস
৮. auth ERROR: ...
৯. সবচেয়ে কম ERROR: ...
```

> প্রথম উত্তরটা আমি দিয়ে দিলাম, যাতে বুঝতে পারেন গড়নটা কেমন হবে।
> আর হ্যাঁ — ৪৬,৯০৮ কিন্তু অর্ডারের সংখ্যা না। কেন না, সেটাও এক লাইনে
> লিখে দেবেন।

তারপর ফাইলটা জমা দেবেন — কোথায়, সেটা ক্লাসের গ্রুপে জানিয়ে দেওয়া হবে।

## কয়েকটা কথা

**উত্তর না মিললে হতাশ হবেন না।** কমান্ডটা কী দিয়েছিলেন, সেটা গ্রুপে
লিখুন। ভুল কমান্ড দেখে বোঝা যায় কোথায় আটকেছেন — আর সেটাই সবচেয়ে
কাজের শেখা।

**`solution/` ফোল্ডারটা আগে খুলবেন না।** ওখানে ক্লাসের ল্যাবের সমাধান
আছে, আর তার কিছু অংশ এই অ্যাসাইনমেন্টেও কাজে লাগবে। নিজে চেষ্টা করার
আগে দেখলে শেখাটা হবে না।

**আটকে গেলে সাপোর্ট ক্লাসে আসুন** — রবি, মঙ্গল, বৃহস্পতি রাত ৯টা।
