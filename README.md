# Ostad Data Engineering Bootcamp — Batch 01

এই repo-তে কোর্সের সব data, starter কোড আর ল্যাবের সমাধান থাকবে। প্রতি সপ্তাহে
নতুন ফোল্ডার যোগ হবে।

**ইন্সট্রাক্টর:** সাদাত হাসান · **ব্যাচ শুরু:** ২৮ অক্টোবর ২০২৬

---

## প্রথমবার যা করবেন

সেটআপ গাইডটা ধরে ধরে করুন (লিংক ক্লাসের গ্রুপে আছে)। সংক্ষেপে:

```bash
# 1. এই ফোল্ডারের ভেতরে ঢুকুন
cd ostad-de-bootcamp-main

# 2. সব বসিয়ে নিন (Python, pip, venv, git + .venv তৈরি)
bash setup/setup.sh

# 3. সব ঠিক আছে কি না দেখুন
python3 setup/doctor.py
```

শেষের `SUMMARY:` লাইনটা কপি করে ক্লাসের চ্যাটে পাঠাবেন।

পরের বার টার্মিনাল খুললে প্রজেক্টের পরিবেশ চালু করতে ভুলবেন না:

```bash
source .venv/bin/activate
```

```
  doctor.py         কী ঠিক আছে, কী নেই — বলে দেয়

module-01/          সপ্তাহ ১ — Getting Started
  data/             ল্যাবের data ফাইল

  solution/         ক্লাসের পরে মেলানোর জন্য
```

## ThelaGari (ঠেলাগাড়ি) — আমাদের কাল্পনিক কোম্পানি

পুরো কোর্সে আমরা একটাই কোম্পানির data নিয়ে কাজ করবো — **ThelaGari**, ঢাকাভিত্তিক
একটা অনলাইন গ্রোসারি ডেলিভারি সার্ভিস (সম্পূর্ণ কাল্পনিক, কোনো বাস্তব কোম্পানির
সাথে মিল নেই)।

সপ্তাহে সপ্তাহে data-টা বড় হবে, আর আপনি নতুন নতুন জিনিস দিয়ে সেটা সামলাবেন:

| সপ্তাহ | ThelaGari-র কোন অংশটা |
|---|---|
| ১–৬ | orders-এর CSV ফাইল, server-এর log |
| ৭–৮ | ওদের API, আর ওয়েবসাইট থেকে তোলা দাম |
| ৯–১৩ | পুরো অর্ডার ডেটাবেস — PostgreSQL-এ |
| ১৪–১৭ | warehouse, star schema, রোজকার pipeline |
| ১৮–২১ | Docker, Airflow, dbt দিয়ে সব স্বয়ংক্রিয় |
| ২২–২৪ | data lake, Spark, Kafka, আর ক্যাপস্টোন |

একটা ডোমেইন একবার বুঝে নিলে পরে আর ডোমেইন বোঝায় সময় যায় না — পুরো মনোযোগটা
টেকনিক্যাল জিনিসে দেওয়া যায়।

## নিয়ম

- ল্যাব নিজে করার চেষ্টা করুন, তারপর `solution/` দেখুন। আগে দেখলে শেখাটা হয় না।
- আটকে গেলে প্রশ্ন করার সময় শুধু "কাজ করছে না" লিখবেন না — কী করেছেন, কী error
  এসেছে, সেটা লিখবেন। এই অভ্যাসটা চাকরিতেও কাজে দেবে।
- `data/` ফোল্ডারের ফাইল বদলাবেন না। নিজের আউটপুট নিজের ফোল্ডারে রাখুন।
