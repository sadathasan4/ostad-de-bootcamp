# লেভেল ১ — শুধু bkash

**লক্ষ্য:** `bkash  3টা  ৳2484.00`

## যা বুঝতে হবে

loop প্রতিটা লাইনের জন্য একবার করে চলে। প্রতিবার সে তিনটা জিনিস হাতে পায়:

| নাম | কী থাকে | উদাহরণ |
|---|---|---|
| `amount` | টাকার অঙ্ক, সংখ্যা হিসেবে | `1240.5` |
| `payment` | কোন মাধ্যমে, ছোট হাতের | `"bkash"` |
| `status` | অর্ডারের অবস্থা, ছোট হাতের | `"delivered"` |

এই তিনটা ফাইলে **দেওয়াই আছে** — আপনাকে বানাতে হবে না। নিচের লাইনগুলো
ইতিমধ্যে লেখা:

```python
amount  = float(parts[5].strip().replace("৳", "").replace(",", ""))
payment = parts[6].strip().lower()
status  = parts[7].strip().lower()
```

আপনার কাজ শুধু দুইটা জিনিস — **বাতিলগুলো বাদ দেওয়া**, আর **bkash হলে
যোগ করা**।

## TODO ১ — বাতিল অর্ডার বাদ

loop-এর ভেতরে, `pass` লেখা লাইনটার জায়গায়:

```python
if status == "cancelled":
    continue
```

`continue` মানে — এই লাইনটা এখানেই ছেড়ে দাও, পরেরটায় যাও।

## TODO ২ — bkash হলে যোগ

ঠিক তার নিচে:

```python
if payment == "bkash":
    bkash_total = bkash_total + amount
    bkash_count = bkash_count + 1
```

তারপর `pass` লাইনটা **মুছে দিন**।

# লেভেল ২ — nagad আর card

**লক্ষ্য:**

```
nagad  2টা  ৳908.00
card   1টা  ৳812.00
```

নতুন কোনো loop লাগবে না। ওই একই loop-এ দুইটা জিনিস যোগ হবে।

**ক) উপরে আরো চারটা ঘর বানান** — `bkash_total`-এর ঠিক নিচে:

```python
nagad_total = 0.0
nagad_count = 0
card_total  = 0.0
card_count  = 0
```

**খ) loop-এর ভেতরে `if`-এর পরে `elif` যোগ করুন:**

```python
if payment == "bkash":
    bkash_total = bkash_total + amount
    bkash_count = bkash_count + 1
elif payment == "nagad":
    nagad_total = nagad_total + amount
    nagad_count = nagad_count + 1
elif payment == "card":
    card_total = card_total + amount
    card_count = card_count + 1
```

**গ) নিচে print যোগ করুন** — loop-এর বাইরে, বাঁ দিক ঘেঁষে:

```python
print(f"nagad  {nagad_count}টা  ৳{nagad_total:.2f}")
print(f"card   {card_count}টা  ৳{card_total:.2f}")
```

> লক্ষ্য করুন — তিনটা ব্লকই হুবহু একই গড়নের, শুধু নাম বদলেছে। কপি করে
> নাম বদলে নিলেই হবে। **কিন্তু সব নাম বদলেছেন কি না দেখে নেবেন** — এখানেই
> সবচেয়ে বেশি ভুল হয়।

# লেভেল ৩ — বাকি দুইটা

**লক্ষ্য:**

```
rocket            1টা  ৳232.25
cash on delivery  2টা  ৳661.50
```

`rocket`-এর জন্য আরেকটা `elif`, আগেরগুলোর মতোই।

`cash on delivery`-র জন্য শেষে `else`:

```python
else:
    cash_total = cash_total + amount
    cash_count = cash_count + 1
```

> **কেন `else`?** ফাইলে ওটা দুই বানানে আছে — `Cash on Delivery` আর
> `CASH ON DELIVERY`। `.lower()` দুইটাকেই এক করে দেয়, কিন্তু `else`
> ব্যবহার করলে বানান নিয়ে ভাবতেই হয় না — বাকি সব এখানে এসে পড়বে।

## শেষে মিলিয়ে দেখুন

```python
grand = bkash_total + nagad_total + card_total + rocket_total + cash_total
print()
print(f"সব মিলিয়ে: ৳{grand:.2f}")
```

**৳5097.75** আসতে হবে। এটা ক্লাসের ল্যাবের মোট টাকার সমান। না মিললে
কোথাও একটা ঘর বাদ পড়েছে।
