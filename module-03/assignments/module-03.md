# লেভেল ১ — payment ধরে হিসাব

**ফাইল:** `week-03/payment_totals.py`

`module-02/data/raw_sales.txt` থেকে বের করুন কোন payment method-এ কত টাকা।

বাতিল অর্ডারগুলো বাদ দেবেন।

### লক্ষ্য

```
payment ধরে হিসাব (বাতিল বাদে)

bkash             3টা   ৳2484.00
nagad             2টা   ৳908.00
card              1টা   ৳812.00
rocket            1টা   ৳232.25
cash on delivery  2টা   ৳661.50

সব মিলিয়ে: ৳5097.75
```

ধাপে ধাপে করতে চাইলে `class-05.md` আর `class-05-starter.py` খুলুন —
ওখানে ছোট ছোট ভাগে করা আছে।

### যা মনে রাখবেন

- জমার ঘরগুলো **loop-এর বাইরে**
- `.lower()` না দিলে `BKASH` আর `bkash` আলাদা হয়ে যাবে
- `সব মিলিয়ে ৳5097.75` — এটা ল্যাবের মোট টাকার সমান, মিলিয়ে দেখবেন

# লেভেল ২ — function-এ ভাগ করুন

**ফাইল:** `week-03/payment_totals.py` (একই ফাইল, গুছিয়ে লেখা)

লেভেল ১-এর কোডটাই, কিন্তু এবার কাজগুলো আলাদা function-এ।

### অন্তত এই তিনটা function বানাবেন

```python
def clean_amount(text):
    """৳ আর কমা সরিয়ে সংখ্যায় ফেরত দিন।"""
    ...

def taka(amount):
    """1240.5  →  "৳1240.50" """
    ...

def read_lines(path):
    """ফাইল পড়ে লাইনগুলোর list ফেরত দিন।"""
    ...
```

তারপর loop-এর ভেতরে এগুলো ডেকে আনবেন।

### তিনটা নিয়ম

1. **প্রতিটা function কিছু `return` করবে** — `print` না। যে function হিসাব
   করে সে return দেয়, যে দেখায় সে print করে।
2. **সব print একসাথে, শেষে।** হিসাবের function গুলো কিছু ছাপাবে না।
3. **শেষে `main()` বানান** আর নিচে লিখুন:

```python
if __name__ == "__main__":
    main()
```

### উত্তর বদলাবে না

লেভেল ১ আর লেভেল ২-এর আউটপুট **হুবহু এক** হতে হবে। কোডটা বদলেছে,
উত্তরটা না। এটাই যাচাই করার সবচেয়ে সহজ উপায় — মিলে গেলে বুঝবেন ভাগ করতে
গিয়ে কিছু ভাঙেনি।

# লেভেল ৩ — নিজের module

**ফাইল দুইটা:** `week-03/my_tools.py` আর `week-03/payment_totals.py`

### ক) `my_tools.py` বানান

লেভেল ২-এর function গুলো এই ফাইলে সরিয়ে নিন — `clean_amount`, `taka`,
আর আপনার বানানো অন্য যেকোনোটা।

নিচে একটা ছোট পরীক্ষা রাখুন:

```python
if __name__ == "__main__":
    print(clean_amount(" ৳ 1,240.50 "))    # 1240.5
    print(taka(1240.5))                     # ৳1240.50
```

চালিয়ে দেখুন:

```bash
python3 week-03/my_tools.py
```

### খ) `payment_totals.py` থেকে import করুন

```python
import my_tools

amount = my_tools.clean_amount(parts[5])
```

### আউটপুট আবারো একই

তিনটা লেভেলেই একই সংখ্যা আসবে। পার্থক্য শুধু কোডটা কতটা গোছানো।

> **যদি `ModuleNotFoundError` আসে** — দুইটা ফাইল এক ফোল্ডারে আছে কি না দেখুন,
> আর `import my_tools` লিখেছেন কি না, `import my_tools.py` না।

## আটকে গেলে

| যা দেখছেন | কী করবেন |
|---|---|
| `TypeError: 'NoneType' has no len()` | function-এ `return` দিতে ভুলে গেছেন |
| `ModuleNotFoundError: No module named ...` | দুইটা ফাইল এক ফোল্ডারে নেই, বা import-এ `.py` লিখেছেন |
| `NameError: name 'taka' is not defined` | সামনে `my_tools.` লিখতে ভুলে গেছেন |
| সব `None` ছাপছে | function বানিয়েছেন, ভেতরে `return` নেই |
| সব টাকা একটাই ঘরে | `.lower()` দিতে ভুলে গেছেন |
| হিসাব দশবার ছাপছে | `print`-গুলো loop-এর ভেতরে রয়ে গেছে |
| `FileNotFoundError` | repo-র মূল ফোল্ডার থেকে চালাচ্ছেন কি না দেখুন |
| মোট মিলছে না | `cancelled`-টা বাদ দিয়েছেন তো? |

error-এর **শেষ লাইনটা** পড়বেন। না বুঝলে পুরোটা কপি করে গ্রুপে পাঠাবেন —
স্ক্রিনশট না, লেখা।
